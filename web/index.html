ARCHITECTURAL PHASES

End-to-End Multi-Stage Pipeline

A strict 7-phase compilation process compliant with modern compiler theory and FAST-NUCES CS 4031 viva requirements.

01
Lexical Analysis
Flex (Lex)

Scans source tokens, classifies colloquial keywords, identifiers, constants, and strips comments with line tracking.

02
Syntax Analysis
Bison LALR(1)

Validates context-free grammar with zero shift/reduce conflicts, enforcing structured Pakistani slang blocks.

03
Abstract Syntax Tree
C++17 AST Node Hierarchy

Constructs strongly typed AST node classes with polymorphic tree traversal, memory safety, and pretty-printing.

04
Semantic Analysis
Scoped Symbol Tables

Enforces lexical block scope nesting, strict type checking, operator compatibility, and variable shadowing resolution.

05
Three-Address Code
Linear Quadruples

Translates AST into linear IR quadruples (Operator, Arg1, Arg2, Result) with synthetic temporaries and branch labels.

06
Code Optimization
Basic Blocks & Passes

Leader detection partitions CFG into basic blocks; applies constant folding, dead-code elimination, and copy propagation.

07
Target Codegen & VM
MIPS32 & In-Memory VM

Generates standard MIPS32 assembly with register allocation ($t0-$t9, $s0-$s7, $v0) and executes immediately via runtime VM.
